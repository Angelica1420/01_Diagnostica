Fase 1: Digital02
El Problema

El estado flotante.

Imagina que conectas un pulsador directamente al ESP32 sin nada más. Cuando no lo presionas... ¿qué voltaje lee el pin GPIO4?

Piénsalo

Si el circuito está "abierto", el pin actúa como una antena. Capta ruido electromagnético. Su estado es impredecible.

¿Cómo obligamos al pin a leer 0V (LOW) cuando el botón no está presionado?

Fase 1: Digital03
La Solución

Resistencia Pull-Down.

  • Obliga al circuito a conectarse a GND (0V) a través de una resistencia de 10kΩ.
  • Cuando presionas el botón, la corriente de 3.3V "supera" la resistencia y el pin lee HIGH.
  • En código: if (digitalRead(4) == HIGH) encenderá el LED correspondiente.

Fase 2: Analógico04
Matemáticas

El lenguaje del ESP32.

Giras el potenciómetro a la mitad. El voltaje real es 1.65V. Pero el ESP32 no entiende "Voltios". Entiende de bits.

Resolvamos

El ESP32 tiene un ADC de 12 bits. Esto significa que puede contar hasta 212 valores.

Si el mínimo es 0 y el máximo es 4095 (para 3.3V)... ¿Qué número entero leerá analogRead(34) si estás exactamente en la mitad del potenciómetro?

Fase 2: Analógico05
La Fórmula

De bits a Voltios.

  • El valor a la mitad es aprox 2047.
  • Para mostrar el voltaje en pantalla, usamos regla de tres:

float voltaje = lecturaADC * (3.3 / 4095.0);
