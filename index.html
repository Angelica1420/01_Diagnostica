Fase 1: Digital05
El Problema

El estado flotante.

Imagina que conectas un pulsador directamente al ESP32 sin nada más. Cuando no lo presionas... ¿qué voltaje lee el pin GPIO4?

Piénsalo

Si el circuito está "abierto", el pin actúa como una antena que capta ruido electromagnético. Su lectura oscila caóticamente.

¿Cómo obligamos al pin a leer 0V (LOW) de forma fija cuando el botón no está presionado?

SocráticoPress Right ➔
Fase 1: Digital06
La Solución

Resistencia Pull-Down.

  • ➔ Conecta una resistencia de 10 kΩ desde el pin a GND.
  • ➔ Al presionar, los 3.3V superan la resistencia y el pin lee HIGH.
bloque_1.ino 
int estado = digitalRead(4);

if (estado == HIGH) {
  digitalWrite(23, HIGH); // LED Rojo ON
  digitalWrite(22, LOW);  // LED Verde OFF
} else {
  digitalWrite(23, LOW);  // LED Rojo OFF
  digitalWrite(22, HIGH); // LED Verde ON
}

Fase 2: Analógico07
Matemáticas

El lenguaje del ESP32.

Giras el potenciómetro a la mitad (1.65V). Pero el microcontrolador no mide "Voltios". Mide bits.

Resolvamos

El ESP32 tiene un ADC de 12 bits (212 = 4096 valores: 0 a 4095).

Si 0V = 0 y 3.3V = 4095... ¿Qué número entero leerá analogRead(34) si estás en la mitad del potenciómetro?

SocráticoPress Right ➔
Fase 2: Analógico08
La Fórmula

De bits a Voltios.

  • ➔ El valor en la mitad es aprox 2047 (ADC).
  • ➔ Dividimos siempre para 4095.0 como float.
bloque_2.ino 
int lecturaADC = analogRead(34);

// Regla de tres directa (0 a 3.3V)
float voltaje = lecturaADC * (3.3 / 4095.0);

Serial.print("ADC: ");
Serial.print(lecturaADC);
Serial.print(" -> Voltaje: ");
Serial.println(voltaje, 2);
